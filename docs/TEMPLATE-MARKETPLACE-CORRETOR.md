# Meu Site — Templates e domínio (guia do corretor)

## Os três produtos

| Produto | O que é | Preço |
|---------|---------|-------|
| Meu Site automático | Página padrão da assinatura | Incluído |
| Template profissional | Layout da galeria | R$ 97 / 2 meses (configurável) |
| Página Premium | Produção exclusiva | R$ 497 |

Não se substituem. Você pode ter Meu Site, contratar um template e ainda solicitar a Página Premium.

## Escolher um template

1. Painel → **Meu Site** → **Templates**
2. Filtre por categoria, busque ou use selos (Novo, Recomendado…)
3. **Visualizar demonstração** (dados de exemplo — não altera seu site)
4. Alterne Desktop / Tablet / Celular
5. **Escolher template** → personalize título/WhatsApp → pagamento simulado
6. Após confirmação, sua URL pública usa o novo visual

## Renovar

Em **Visão Geral**, use **Renovar por mais 2 meses** ou checkout com `?renew=1`.

## Trocar template

Na galeria, escolha outro modelo. Dados (imóveis, CRECI, contatos, SEO, domínio) são preservados. Seções inexistentes no novo modelo ficam salvas, mas ocultas.

## Voltar ao Meu Site básico

Em Visão Geral, Templates (`?action=basic`) ou Configurações → **Voltar para Meu Site básico**. Nada é apagado.

## Domínio

**Já tenho domínio:** informe o domínio → anote A/CNAME/TXT → configure no registrador → aguarde validação (ou simule no painel).

**Quero comprar:** busque o nome → veja preço de registro + taxa de configuração → pedido fica em **processamento manual** até haver provedor real (não prometemos registro automático ainda).

## Problemas comuns

- **Demo mudou meu site?** Não. Só contratação/ativação muda.
- **Template sumiu após 2 meses?** Expirou: volta ao básico; renove para reativar.
- **Imóvel novo não aparece?** Publique no painel e autorize no site; templates leem a mesma lista.
